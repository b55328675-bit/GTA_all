# GTA ALL — мод-пак

Это не «сборка из интернета с DLL на 3 ГБ». Внутри — установщик, конфиги и ссылки. Игровые файлы, тексты и чужие озвучки не распространяются.

## Что делает установщик

1. Находит игру через Steam (или спрашивает путь вручную).
2. Делает резервную копию каждого заменяемого файла в папку `backup_YYYYMMDD_HHMMSS`.
3. Скачивает открытые моды с официальных GitHub-релизов в `_downloads`.
4. Распаковывает и раскладывает файлы по нужным папкам.
5. Настраивает разрешение, 60 FPS и другие параметры.
6. Записывает список изменённых файлов в `installed-files.txt`.

## Установка

1. Распакуйте ZIP в любую папку.
2. Запустите **Install.cmd**.
3. Если Windows запросит права администратора — разрешите.
4. Если игра не найдена автоматически, укажите папку с `gta_sa.exe` / `gta3.exe` / `gta-vc.exe` / `GTAIV.exe`.
5. После установки включите в игре **Frame Limiter** (Display Setup).
6. Русскую озвучку поставьте отдельно по ссылке из `RU-LOCALIZATION.txt`.

## Офлайн-режим

Если интернет на игровом ПК недоступен:

1. Скачайте все ZIP из `manifest.json` на другом ПК.
2. Положите их в папку `_downloads` рядом с `Install.ps1` с именами `id.zip` (например, `silentpatch.zip`).
3. Запустите:

```bat
Install.cmd -Offline
```

## Удаление

Запустите **Uninstall.cmd**. Установщик восстановит файлы из последней резервной копии. Если резервной копии нет — удалит только те файлы, которые ставил сам.

Если после удаления что-то не так, проверьте целостность файлов игры в Steam:

> Steam → ПКМ по игре → Свойства → Установленные файлы → Проверить целостность файлов игры.

## Если что-то пошло не так

- **Игра не находит .asi-плагины** — проверьте, что `dinput8.dll` (для III/VC) или `vorbisFile.dll` (для SA) лежит в корне игры.
- **Вылет при запуске** — удалите недавно добавленные моды по одному и проверьте `install.log`.
- **Нет 60 FPS** — включите Frame Limiter в игре; мод поднимает лимит, а не отключает его.
- **Сломалось сохранение** — не используйте старые сохранения после смены версии игры. Бэкап сохранений — в `Documents\GTA San Andreas User Files` или `Documents\Rockstar Games`.
- **Steam-версия не моддится** — для полного моддинга классики лучше версия 1.0. Установщик предупредит, если версия не подходит.

## Права

Пак содержит только собственный код, конфиги и ссылки. Моды принадлежат их авторам и распространяются по своим лицензиям (обычно MIT). Игровые файлы, тексты и озвучки не включены. Подробности — в `NOTICE.md` и `MOD-SOURCES.txt`.
