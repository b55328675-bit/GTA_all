# GTA V — настройки 60 FPS

GTA V Enhanced на современном ПК обычно держит 60 FPS без модов. Если нет — начните с этих настроек.

## Базовый профиль (1080p / 60 FPS)

| Параметр | Значение |
|---|---|
| Разрешение | 1920×1080 |
| Режим экрана | Полноэкранный |
| VSync | Выкл (если есть G-Sync/FreeSync) |
| Direct3D | 11 или 12 — что стабильнее |
| Качество текстур | Высокое |
| Качество шейдеров | Высокое |
| Тени | Высокие / Средние |
| Сглаживание | FXAA + MSAA 2x |
| Дальность прорисовки | 60–80% |
| Плотность трафика | 50–70% |
| Плотность пешеходов | 50–70% |
| Качество травы | Среднее |
| Постобработка | Средняя |
| Motion Blur | Выкл |
| Depth of Field | Выкл |

## Если FPS ниже 60

1. Снизьте дальность прорисовки до 50%.
2. Отключите MSAA, оставьте FXAA.
3. Снизьте качество теней до среднего.
4. Ограничьте FPS на 60 через драйвер NVIDIA/AMD или RTSS.
5. Обновите драйвер видеокарты.
6. Закройте браузер и Discord с аппаратным ускорением.

## Если есть монитор 144 Гц

GTA V поддерживает высокие частоты, но в онлайне может срабатывать ограничение. Для сюжета можно поставить 100–144 FPS, если система тянет. Для стабильности лучше зафиксировать 60 FPS.

## Не делайте так

- Не ставьте «ультра» на слабой видеокарте — это не про красоту, а про слайд-шоу.
- Не включайте VSync на 30 Гц мониторе — получите задержку.
- Не используйте моды, которые «разгоняют» игру до 240 FPS: анимации и физика могут сломаться.
